# Source partitions

`split_manifest.json` assigns an entire conversation or physical label source to exactly one split. All screenshots from a conversation and all photos, crops and variants of one label belong to that source group. Source and artifact identifiers are safe fixture IDs, never names, phone numbers or paths.

The hand-authored judge screenshots generated by `apps/api/pocketdokani/demo.py` are **constructed development inputs**, not model results. The judge uses the same live model-analysis paths as the seller. Historical parcel experiments and generated variants derived from private label/bag photos stay ignored with their ground truth and detailed outputs. Related scenes and variants remain in the same source group. No held-out evaluation result is claimed.

Before any model experiment, register every available source group with `kind` (`conversation` or `label`), `split` (`development` or `evaluation`), `provenance` (`constructed`, `anonymised` or `private`) and all its `artifact_ids`. Run `uv run python scripts/check_split_manifest.py` before using any source. Keep private media/ground truth under ignored `evals/private/` and the ID-to-path mapping there. The validator checks declared grouping; the human preparing the data must identify related sources and near duplicates.

Keep evaluation sources untouched by prompts, tuning and retries. If an evaluation failure informs a change, move that **whole source group** to development and acquire fresh sources for any new held-out claim. Freeze and record the manifest revision with every future evaluation run.
