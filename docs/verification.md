## Open acceptance and release gates

- Rehearse the current deployed `/judge` flow in fresh desktop and physical-phone sessions; test microphone permission denial, camera capture, upload limits and deliberately slow/ambiguous-write recovery.
- Evaluate actual model outputs against ground truth without tuning on held-out sources. Neither the live-service rehearsal nor sample controls supply accuracy results.
- Use a genuine order for the complete live courier workflow when one exists; never create an artificial shipment for a pilot claim. Automatic courier status sync is not implemented; net payout due is unknown without fee records.
- Finish the [owner release checklist](https://github.com/afif-fahim/pocketdokani/issues/7): review tracked content/history findings, choose a license, make the repository public, publish the video and verify repository/demo/video without owner sign-in. No video link or license is supplied yet.
